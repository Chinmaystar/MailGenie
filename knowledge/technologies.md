# Kelvor — Technology Stack & Capabilities

This is a capability list — what Kelvor builds with. Never frame it as project history; experience claims come only from portfolio.md / case-studies.md.

## Frontend
- **React 18+** (hooks, suspense, server components)
- **Next.js 14+** (App Router, Server Actions, Middleware)
- **TypeScript** (strict mode, type-safe APIs)
- **Tailwind CSS** (utility-first, design systems)
- **Shadcn/UI / Radix** (accessible component primitives)
- **React Hook Form + Zod** (forms & validation)
- **TanStack Query / React Query** (server state)
- **Zustand / Jotai** (lightweight client state)
- **Framer Motion** (animations)
- **Recharts / Tremor** (dashboards & charts)

## Backend
- **Node.js 20+** (ESM, native fetch, test runner)
- **Next.js API Routes / Route Handlers** (for full-stack apps)
- **Express / Fastify** (standalone APIs)
- **tRPC** (end-to-end type-safe APIs)
- **PostgreSQL** (primary relational DB)
- **Prisma / Drizzle ORM** (type-safe database access)
- **Redis** (caching, sessions, queues — when needed)
- **BullMQ** (background jobs — when needed)

## Ecommerce Platforms
- **Shopify / Shopify Plus** (Liquid, Dawn, Hydrogen, Checkout Extensions, Functions)
- **Medusa v2** (headless commerce engine)
- **Saleor** (GraphQL-first headless commerce)

## Payments
- **Razorpay** (Checkout, Subscriptions, Route, Payment Links, Webhooks)
- **Stripe** (Checkout, Billing, Connect, Elements, Radar, Webhooks)
- **PayPal** (Standard, Advanced, Braintree)
- **Cashfree** (Indian market alternative)

## Shipping & Logistics (India-focused)
- **Shiprocket** (Courier aggregation, tracking, NDR, COD reconciliation)
- **Delhivery** (Direct API, surface & express)

## DevOps & Infrastructure
- **Vercel** (Next.js native, edge functions)
- **AWS** (ECS Fargate, RDS, S3, CloudFront, Lambda)
- **GCP** (Cloud Run, Cloud SQL, Cloud Storage)
- **Railway / Render / Fly.io** (simpler deployments)
- **Docker / Docker Compose** (local & CI)
- **GitHub Actions** (CI/CD)

## Databases
- **PostgreSQL** (default choice)
- **MySQL** (legacy compatibility)
- **SQLite** (local dev, small tools, edge)
- **ClickHouse** (analytics / event storage)
- **MongoDB** (rare, only when document model is clearly better)

## Testing
- **Vitest** (unit / integration)
- **Playwright** (E2E)
- **Testing Library** (React component testing)
- **MSW** (API mocking)

## Observability
- **Sentry** (error tracking)
- **Logtail / Better Stack** (structured logging)
- **PostHog** (product analytics)
- **OpenTelemetry** (traces & metrics)

## What we DON'T do (by choice)
- WordPress / WooCommerce (unless strictly migration)
- Legacy PHP / .NET maintenance
- AI/ML model training (we integrate APIs, don't train models)
- Blockchain / Web3
- No-code / low-code platforms (Bubble, Webflow, etc.)
